About

AI가 채우지 못하는 마지막 2%,
‘라스트 마일’의 가치

이제 누구나 프롬프트 몇 줄로 코딩 AI를 쓰는 시대입니다. 역설적으로, AI가 그럴싸한 코드를 빠르게 뱉어내도 복잡한 비즈니스 도메인을 이해하고 시스템 전체의 안정성과 아키텍처를 책임지는 것은 결국 사람 개발자의 몫입니다.

강산이 한 번 반 바뀌는 시간 동안 쌓은 기본기와 디버깅 내공으로, AI가 제안하는 코드의 맥락과 허점을 정확히 짚어냅니다.

저는 Cursor, Claude Code, Antigravity 같은 최신 AI 에이전트를 단순 보조 도구가 아니라 ‘지치지 않는 주니어 개발자’처럼 적극적으로 리드합니다. AI의 ‘빠른 초안 작성’과 시니어의 ‘정밀한 검증 능력’을 결합해, 주력 분야인 PHP 아키텍처를 더 견고히 다지는 것은 물론 Python 기반 데이터 처리와 모바일 앱 개발까지 기술 스펙트럼을 확장했습니다.

발전과 화합을 중시합니다. 사회는 혼자 사는 것이 아니라는 믿음으로 팀과 잘 어울려 프로젝트를 완성해 왔고, 도구의 변화에 휩쓸리지 않고 도구를 지배하여 비즈니스의 실질적인 생산성 혁신을 리드하는 개발자로 계속 성장하고 있습니다.
